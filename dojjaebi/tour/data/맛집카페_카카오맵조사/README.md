# 동해시 맛집·카페 전수조사 (카카오맵 기준, 2026-10-21)

한국관광데이터랩 '지역 맛집' 랭킹(인기관광지_지역_맛집_외지인/전체/현지인) 3개 시트를 합쳐 중복 제거한
119곳 + 기존 프로토타입에 있던 영빈관횟집 1곳, 총 **120곳**을 카카오맵에서 전수 조사한 결과입니다.

## 파일
- `동해_맛집_카페_정리.md` — 사람이 읽는 정리본. 음식점(86곳, 메뉴별 9개 분류)과 카페/찻집(34곳)을 나누고,
  업소별 주소·전화·현재 영업상태·요일별 영업시간(브레이크타임 포함)·가격대·대표메뉴를 담았습니다.
  카카오맵에서 끝내 확인 안 된 4곳(토마도우, 말똥도나스, 짬뽕타운동해점, 차이나웍평릉점)은 폐업/상호변경
  추정 근거와 함께 별도 표시했고, 빠뜨리지 않았습니다.
- `동해_맛집_카페_전체데이터.json` — 위 120곳 전체의 구조화 원본 데이터(배열). 각 항목:
  `idx`(0~119, 엑셀 목록 순서), `excel_name`/`excel_cat`(엑셀상 이름·분류), 카카오 조회 결과
  `id`(카카오 place id, 못 찾은 4곳은 null), `name`, `status`("Y" 또는 "NOTFOUND_CONFIRMED"),
  `category`, `addr`, `phone`, `headline`/`headline_info`(현재 영업 상태 문구), `week`(요일별 영업시간
  배열, `d`/`on`/`brk`/`off`), `menu_kw`(대표메뉴·특징), `price`(₩ 개수), `is_cafe`(카페 여부),
  `note`(엑셀명과 카카오 등록명이 다른 경우 등 비고).

## 참고: 기존 places.js `eateries` 와의 관계
현재 `dojjaebi/tour/places.js`는 `node 수집.mjs`로 자동 생성되며, 그 안의 `eateries` 배열에는
관광공사 TourAPI 기준 음식점 4곳(오부자냄비물회, 부흥횟집, 오뚜기칼국수, 영빈관횟집)만 들어 있습니다.
이 폴더의 데이터는 그보다 훨씬 넓은 120곳을 다루지만, `eateries` 스키마(위도/경도, `menu`, `open`
분 단위 배열, `story` 등)와는 출처·형식이 달라 자동 생성 파일(`places.js`)을 직접 고치지 않고
원본 조사 자료로만 이 폴더에 올려둡니다. `places.js`에 반영하려면 각 업소의 좌표(lat/lng) 확보 및
`수집.mjs`/`places.base.mjs` 쪽 작업이 추가로 필요합니다.
